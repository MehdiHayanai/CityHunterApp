# Archive Directory

This directory contains historical development documentation that was created during the initial development of CityHunter.

## Contents

### prompts-lib/

Historical development documentation organized by feature area:

- **agent_guide/** - API agent implementation guides
- **refactor/** - Refactoring plans and strategies
- **specs/** - Original data models and backend specifications
- **walks/** - Walk feature implementation documentation (10 files)
- **xp_and_activity/** - XP system implementation documentation (5 files)

## Purpose

These files represent the development journey and decision-making process during the project's creation. They are preserved for:

- **Historical reference** - Understanding why certain decisions were made
- **Learning** - Seeing how the project evolved
- **Context** - Background for future refactoring or feature additions
